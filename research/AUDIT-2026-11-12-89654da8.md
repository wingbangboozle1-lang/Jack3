## Findings and disposition

1. The repository-only `scripts/projection.py` labels its 0.0486 Treasury anchor as 2026-11-09, whereas FRED's value on that date is 4.88%. This script is excluded from the public artifact. A concurrent integration added F-25 on Flagged for Review; do not use the script until independently repaired and its assumptions reviewed.
2. The test parser had a `tags` set but never populated it, so its prohibited-tag assertion was ineffective. Other independent string checks existed, but this specific regression gate was defective. Fixed the parser and added positive detection tests.
3. Jekyll parity compared all expected files but ignored unexpected non-HTML files. Such files could leak. The parity gate now rejects any extra file; a synthetic test confirmed an unexpected binary file is rejected. The actual Jekyll build is tested by CI, not locally.
4. The prior site presented a ten-year minimum extension and a 24–36 month sale timetable as fixed gates despite missing the executed lease and owner circumstances. The public pages now call for evidence-based terms and immediate deadline review, with the marketing window labelled illustrative. This is judgment, not a source-verified rule.
5. A concurrent integration independently added a dedicated source-linked suggestions page. Sources provide context, not endorsement of proposed actions. The page does not collect personal information.
6. Retained blanks for property, lease, financial and individual details. No credible site-specific valuation, calibrated projection, or personalized optimum is possible without them; adviser review must be private. No private records were accessed.
