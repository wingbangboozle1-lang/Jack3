4 · Projection system rules (how to keep this reliable)

  • Inputs only from linked sources; each input row on this site names its source and class (OFFICIAL / SEC / INDUSTRY / MODEL / FLAGGED).
  • Unverifiable values stay blank and are listed on Flagged for Review — never inferred.
  • Official sources take precedence over industry sources; where two official sources diverge (DOF vs SCAG), both are shown and the conservative one drives planning.
  • Model outputs are labeled [MODEL] and recomputed from the cited inputs; property NOI must be supplied privately (never published) to produce actual dollar values.
  • Refresh cadence: re-pull Fed/Treasury monthly, Census/EDD on release, Boulder Group quarterly, CAL FIRE/FEMA on map updates.
