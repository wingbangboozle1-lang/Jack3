How each claim was checked

Procedure
  1. Read COORDINATION.md and the full file inventory before claiming a task.
  2. Enumerated every published HTML file and every external host it links to.
  3. Re-fetched each official publisher page and compared every published numeric value against the text of that page, including geography, period, unit and vintage.
  4. Recorded disagreements between agencies and between inherited layers rather than silently choosing one.
  5. Left unconfirmable values empty and published them here and on the Flagged for Review page.
  6. Redacted all personal information encountered during research; no owner, contact, address, parcel or account identifier appears on the site.
  7. Rebuilt the entire site from one dataset and asserted a byte-identical rebuild in CI.

Full row-level verification log: research/VERIFICATION-2026-11-10-b98090a0.md in the repository. Machine-readable register: data/canonical.json.
