Anonymised decision file · Central Los Angeles

Sell before expiry. Buy the term only if the tenant will commit.

A single, reconciled, source-linked decision file for a Jack in the Box NNN property whose primary term expires between 2030 and 2035. Built to separate what government and issuer sources actually say from what an owner might hope.

Recommendation

Sell before the lease expires — and buy the term only if the tenant will commit first.

On the committed model, selling now has the highest worst-case present value of every strategy tested: 11.62 R in the pessimistic scenario, against 1.18 R for renewing with the incumbent to a 2030 expiry. Renewing ranks last in both the base and the pessimistic scenarios. If — and only if — the tenant will sign a long extension now, extending first and then selling the lengthened lease has the best rank stability of any strategy.

R = one year of the property's current contractual base rent. The model is normalised because the rent, basis and building size were never supplied. Multiply by your own rent to read it in dollars. Full method: Projections · Decision.

What this file will not tell you

There is no address, parcel number, rent roll, purchase price, building size or debt schedule in this file, because none was supplied and researching the owner or the parcel would breach the privacy boundary. Every site-specific number is therefore blank and listed on Flagged for review.

No commercial capitalisation rate is published by any U.S. government agency. Cap rates on this site are either labelled industry data or treated as a swept assumption — never as verified fact.

How to read a row

Verified re-read on the publisher's own page during this integration, on 2026-11-07. Source-linked carries an official or SEC link and was read when first captured. Analysis is our arithmetic or judgement. Industry data is private research and is never scored as verified. A blank cell means the value could not be confirmed from an official source — it is never estimated.
