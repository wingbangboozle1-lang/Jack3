How this file was built, and the limits built into it

The privacy boundary, the verification vocabulary, the model's construction and what is deliberately missing.

Privacy

Personal information privacy is the primary constraint on this project, and it is enforced mechanically rather than promised.

Rule Implementation
No identifier of the property or its ownerThe asset is "Asset A". No address, parcel number, owner name, officer name, email, phone or taxpayer identifier appears in any page, table or data file.
No personal information is collectedThere are no forms, no accounts, no cookies, no analytics, no third-party scripts and no external fonts or images. Everything is static HTML, CSS and a few lines of local JavaScript.
No owner researchNo attempt was made to identify the owner, the franchisee or any individual. Private lease and financial documents were not sought and are not published.
Build-time gatetools/check_report.py scans every published file for email addresses, phone numbers, street addresses, parcel numbers, taxpayer identifiers and tenant officer names. The build fails on any match.
Repository metadataCommit metadata is infrastructure, not project data. It is not reproduced on the site. Flagged as F-20 so it can be neutralised if the repository is shared.

Verification standard

Three things are kept strictly apart and labelled everywhere:

  1. Observations. Published by a government body or filed with the SEC. Re-read on the publisher's page on 2026-11-07 where marked verified, otherwise linked and read on capture.
  2. Analysis. Our arithmetic, scenarios, rankings and scores. Conditional by construction.
  3. Industry data. Private research. Never scored as verified, never used as a model input.

A value that could not be confirmed from an official source is blank. The blanking is enforced in the generator: cell() cannot render a value for a row whose status is unverified.

The model

The projection model is deterministic and committted to the repository. It uses one official anchor — the U.S. Treasury 10-year par yield of 4.19% at 2026-01-02, plus a declared risk premium — and otherwise sweeps stated assumption ranges. All fourteen strategy-by-expiry combinations are computed. No randomness, no network calls, no fitted parameters: running it twice produces identical output.

Assumption classes are shown on Projections. The cap-rate range is the dominant uncertainty and is deliberately wide.

Reproducibility

python3 tools/build_report.py    # data/report_data.py + model -> report/
python3 tools/check_report.py    # links, sources, blanks, privacy, determinism

The build writes only to report/. It does not touch the root pages, docs/, analysis/, brief/, pages/ or decision-file/, all of which remain published as archive.

What is deliberately absent

  • Any dollar valuation of the property. No rent, basis or building size was supplied.
  • Any cap rate presented as fact. None is officially published.
  • Any school rating or traffic count for the parcel. Both require the address.
  • Any claim about the owner's circumstances, net worth or tax position.
  • Any prediction of what this specific restaurant will do. Only the counterparty's disclosed behaviour is reported.
