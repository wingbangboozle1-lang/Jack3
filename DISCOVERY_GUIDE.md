## Section 1: Critical Blockers (Must Obtain Before Any Decision)

### 1.1 Executed Lease Agreement

**Why:** Without the lease, NO valuation, NO renewal analysis, NO defensible decision is possible.

**Where to Find:**
- Owner's files (original closing documents)
- Title company (if escrow closed recently)
- Tenant (request copy from property manager)
- Attorney's office (if lease was negotiated by counsel)

**What to Look For:**
- [ ] Exact lease commencement and expiry dates
- [ ] Renewal options (number, duration, terms)
- [ ] Base rent amount and escalation terms
- [ ] NNN obligations (who pays taxes, insurance, maintenance)
- [ ] CAM (Common Area Maintenance) charges
- [ ] Notice periods (for renewal, termination, rent changes)
- [ ] Assignment and subletting provisions
- [ ] Default and cure provisions
- [ ] Guaranty provisions (corporate or personal)
- [ ] Early termination options
- [ ] Relocation clauses
- [ ] Exclusivity provisions

**Action Steps:**
1. **Day 1:** Locate lease in owner's files
2. **Day 1:** If not found, contact title company from purchase
3. **Day 2:** If still not found, request from tenant/property manager
4. **Day 3:** If unavailable, engage attorney to help locate
5. **Day 4:** Once obtained, redact all personal information
6. **Day 5:** Extract key terms for analysis (anonymized)

**Estimated Time:** 1-5 days  
**Estimated Cost:** $0 (unless attorney assistance needed: $200-500/hr)  
**Privacy Note:** Redact all addresses, names, and financial figures before sharing with advisors. Use "Asset A" designation.

### 1.2 Property Financials

**Why:** Without NOI, basis, and debt, NO after-tax analysis is possible.

**Where to Find:**
- Owner's accounting records
- Property management statements
- Tax returns (Schedule E, Form 8825)
- Bank statements (rent deposits)
- Mortgage statements
- Insurance policies

**What to Look For:**
- [ ] Current base rent
- [ ] Additional rent (NNN reimbursements)
- [ ] Gross potential rent
- [ ] Vacancy and credit loss
- [ ] Property taxes
- [ ] Insurance premiums
- [ ] Maintenance and repairs
- [ ] Property management fees
- [ ] Other operating expenses
- [ ] Net Operating Income (NOI)
- [ ] Owner's basis (purchase price + improvements)
- [ ] Current mortgage balance
- [ ] Mortgage interest rate
- [ ] Mortgage maturity date
- [ ] Depreciation claimed

**Action Steps:**
1. **Day 1:** Gather last 12 months of rent deposits
2. **Day 1:** Gather last 12 months of operating expenses
3. **Day 2:** Calculate NOI (Rent - Operating Expenses)
4. **Day 2:** Locate purchase documents for basis
5. **Day 3:** Gather mortgage statements for debt info
6. **Day 4:** Calculate debt service coverage ratio (NOI / Annual Debt Service)
7. **Day 5:** Redact all personal information and anonymize

**Estimated Time:** 1-3 days  
**Estimated Cost:** $0  
**Privacy Note:** Financial data is highly sensitive. Only share anonymized summaries with trusted advisors.

### 1.3 Address and APN (Assessor's Parcel Number)

**Why:** Without address/APN, NO site-specific analysis (taxes, hazards, zoning) is possible.

**Where to Find:**
- Owner's files (purchase documents, tax bills)
- Property tax bills
- Title report
- Deed (recorded with county)

**What to Look For:**
- [ ] Full street address
- [ ] City, State, ZIP
- [ ] APN (Assessor's Parcel Number) - Format: 1234-567-890
- [ ] Legal description

**Action Steps:**
1. **Day 1:** Check owner's files for address
2. **Day 1:** Locate property tax bill (has APN)
3. **Day 2:** If not found, search LA County Assessor website
4. **Day 3:** Once obtained, use only for official lookups
5. **Day 4:** Anonymize all public documentation as "Asset A"

**How to Find APN Online:**
1. Go to: [LA County Assessor Property Search](https://assessor.lacounty.gov/)
2. Enter address (if known)
3. Or use interactive map to locate parcel
4. APN will be displayed in search results

**Estimated Time:** 1 day  
**Estimated Cost:** $0  
**Privacy Note:** Address and APN are public records, but should NOT be published. Use only for internal analysis.

**Action Steps:**
1. **Day 1:** Request from tenant (if good relationship)
2. **Day 3:** If tenant uncooperative, request from Jack in the Box franchise relations
3. **Day 7:** Consider hiring industry consultant (if critical)

**How to Estimate (If Data Unavailable):**

### 2.2 Property Tax Information

**Why:** Property taxes are a major expense and affect NOI.

**Where to Find:**
- LA County Assessor's Office
- Property tax bills
- LA County Treasurer and Tax Collector

**What to Look For:**
- [ ] Current assessed value
- [ ] Proposition 13 base year
- [ ] Annual property tax amount
- [ ] Any special assessments
- [ ] Any exemptions

**Action Steps:**
1. **Day 1:** Use APN to look up on LA County Assessor website
2. **Day 1:** Download property tax bill
3. **Day 2:** Calculate effective tax rate (Tax / Assessed Value)
4. **Day 3:** Project future taxes (2% annual cap under Prop 13)

**How to Look Up Online:**
1. Go to: [LA County Assessor Property Search](https://assessor.lacounty.gov/)
2. Enter APN
3. View "Assessment Details"
4. Note: Assessed value = Purchase price (under Prop 13) + 2% annual increases

**Estimated Time:** 1 day  
**Estimated Cost:** $0  
**Official Source:** [LA County Assessor](https://assessor.lacounty.gov/)

### 2.5 Hazard Overlays

**Why:** Hazard zones affect insurance availability/cost and property value.

**Where to Find:**
- FEMA (Flood)
- CAL FIRE (Wildfire)
- USGS/CGS (Earthquake)
- LA County (Various)

**What to Look For:**
- [ ] FEMA Flood Zone (e.g., X, AE, VE)
- [ ] CAL FIRE Fire Hazard Severity Zone (e.g., Moderate, High, Very High)
- [ ] USGS Earthquake Zone (e.g., Alquist-Priolo, Seismic Hazard)
- [ ] Liquefaction potential
- [ ] Landslide potential
- [ ] Methane zone (LA specific)

**Action Steps:**
1. **Day 1:** Use address/APN to check FEMA flood maps
2. **Day 1:** Check CAL FIRE hazard zones
3. **Day 2:** Check USGS earthquake hazards
4. **Day 2:** Check LA County hazard overlays
5. **Day 3:** Compile hazard report

**How to Look Up Online:**

**FEMA Flood Maps:**
1. Go to: [FEMA Map Service Center](https://msc.fema.gov/portal/home)
2. Enter address
3. View flood zone designation

**CAL FIRE Hazard Zones:**
1. Go to: [CAL FIRE Fire Hazard Severity Zones](https://osfm.fire.ca.gov/what-we-do/community-wildfire-preparedness-and-mitigation/fire-hazard-severity-zones)
2. Use interactive map or enter address
3. Note: New zones established in 2025

**USGS Earthquake Hazards:**
1. Go to: [CGS EQ Zapp](https://www.conservation.ca.gov/cgs/geohazards/eq-zapp)
2. Enter address
3. View earthquake zone designations

**Estimated Time:** 1-2 days  
**Estimated Cost:** $0  
**Official Sources:**
- [FEMA](https://msc.fema.gov/portal/home)
- [CAL FIRE](https://osfm.fire.ca.gov/what-we-do/community-wildfire-preparedness-and-mitigation/fire-hazard-severity-zones)

## Section 7: Privacy Protection Protocol

### Rules for Handling Sensitive Information

1. **Never publish:** Address, APN, owner name, tenant name (unless corporate), rent amounts, sale prices, financial data
2. **Always anonymize:** Use "Asset A", "Tenant A", "Owner A" in all public documentation
3. **Secure storage:** Keep all sensitive documents in encrypted, password-protected files
4. **Limited access:** Only share sensitive information with trusted advisors under NDA
5. **Redact before sharing:** Remove all identifying information from documents before sharing
6. **Use code names:** Assign code names to all parties and properties
7. **Destroy when no longer needed:** Securely delete or shred sensitive documents

### Anonymization Checklist

- [ ] Address replaced with "Asset A - Central Los Angeles"
- [ ] APN removed or redacted
- [ ] Owner name replaced with "Owner A" or "the owner"
- [ ] Tenant name replaced with "Tenant A" or "the tenant" (unless corporate Jack in the Box)
