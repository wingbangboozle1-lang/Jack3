# Jack3

Research, decision analysis, and a live GitHub Pages dashboard for a **Jack in the Box** quick-service restaurant property in **central Los Angeles, CA**, held under a **triple-net (NNN) lease expiring sometime in 2030–2035** — evaluating **sell before expiry vs. renew/hold** based on verified official sources (geography, income, schools, population, job growth, market pricing, tenant health, hazards/black swans).

## 🌐 Live site

**https://wingbangboozle1-lang.github.io/Jack3/** — clean dashboard with subpages: Executive Summary · Market Research · Lease & Tenant · Risk Analysis · Projections · Repo Review · Sources · ⚑ Flagged for Review.

- Every table row carries a source link to an official site; unverifiable values are left **blank** and listed on the **Flagged for Review** page — never inferred.
- **Privacy:** all personal information is anonymized with placeholders (`[OWNER NAME REDACTED]`, `[PROPERTY ADDRESS REDACTED]`). No personal information appears anywhere in this repo or on the site.

## Headline recommendation

**Sell before the lease expires (target 2027–2029), via an IRS §1031 exchange** — the 2030–2035 expiry has no contractual renewal right (2026 FDD Item 17), the asset already prices in the 6.87–7.55% franchisee-QSR cap band, and rates are elevated (fed funds 3.75–4.00%, 10Y 4.90%). Hold only if a ≥10-year extension at/above current rent is signed now. Details: [Executive Summary](https://wingbangboozle1-lang.github.io/Jack3/pages/executive-summary.html).
